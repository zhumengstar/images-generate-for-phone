# 2026-05-11 发布说明

## 发布范围

本次发布覆盖图片生成工作台、用户管理、额度套餐、图片编辑加载和远程部署验证。

## 主要变更

### 用户管理与额度

- 新增 `7天100张` 套餐按钮。
- 套餐计算方式按当前额度追加：`当前可用 + 100 / 当前总额度 + 100`。
- 套餐有效期为 7 天，到期后自动恢复到套餐前的总额度。
- 设置普通图片额度时按当前总额度追加，不清空历史使用额度。
- 管理端可展示套餐状态和到期日期。
- 手机端用户管理保留用户列表、搜索、角色筛选、刷新、退出。
- 手机端支持全选当前筛选用户和批量删除。
- 使用额度、最后登录、创建时间支持排序。

### 图片生成与编辑

- 生成结果支持直接进入图片编辑。
- 编辑图片支持多图加载，最多加载 4 张。
- 图片编辑加载增加代理图片缓存，降低重复远程拉图开销。
- 图片代理会校验返回内容为有效图片，避免无效资源进入编辑流程。
- 图片结果耗时显示和结果标题展示做了收敛优化。

### 分享与导航

- 分享按钮逻辑保留，分享点击额度提示按手机端自适应展示。
- 管理员手机端导航保留用户管理入口，避免显示不必要的分享入口。

## 数据兼容

远端部署前已对比本地与远端数据文件格式：

- `data/web_users.json`：用户列表，套餐字段为可选字段。
- `data/ip_image_quotas.json`：额度使用记录字典。
- `data/ip_image_tasks.json`：`{ "tasks": [...] }` 结构。
- `data/image_share_rewards.json`：分享奖励记录字典。

新增字段：

- `quota_package`
- `quota_expires_at`
- `quota_package_base_limit`

这些字段只会在设置套餐时写入；旧数据没有这些字段也可以正常读取。
