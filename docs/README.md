## 核心原则

1. 部署前必须备份远程 `data/`、`config.json`、`.env` 和 Compose 配置。
2. 重新部署不能覆盖运行数据，尤其是用户、额度、任务和分享奖励文件。
3. 本地和远程都以 `/version`、登录、额度、图片生成或任务接口作为基础验收。
4. 未经明确允许，不发布远程服务。
5. 管理员为无限额度，普通用户和访客按各自额度统计。
