# 项目总览

`images-generate` 是一个面向图片生成和图片编辑的 Web 应用，同时保留 OpenAI 兼容接口能力。项目由 FastAPI 后端、Next.js 前端静态构建产物和本地 JSON 数据文件组成，可通过 Docker Compose 作为单容器服务部署。

## 主要能力

- 图片生成：支持文本生成图片，前端以任务方式提交并轮询结果。
- 图片编辑：支持上传参考图进行编辑，当前编辑入口最多加载 4 张图片。
- AI 润色：对生成或编辑提示词进行润色。
- 分享奖励：保留分享按钮，分享链接被访问后可以触发奖励逻辑。
- 用户管理：支持访客、普通用户、管理员，管理员可以设置角色、额度、套餐和删除用户。
- 额度统计：按访客设备、用户设备、管理员会话分别记录使用次数。
- 7 天套餐：可给用户或访客追加 `7 天 100 张` 临时额度。
- OpenAI 兼容接口：提供 `/v1/models`、`/v1/images/generations`、`/v1/images/edits` 等接口。
- 账号池管理：支持本地账号池、CPA、Sub2API 导入和刷新。
- 运维管理：支持查看图片、日志、存储信息、代理测试和配置更新。

## 用户角色

| 角色 | 标识 | 说明 |
| --- | --- | --- |
| 访客 | `guest` | 未登录用户，以 IP 和设备指纹识别，有默认访客额度。 |
| 普通用户 | `user` | 账号密码登录，有默认用户额度或管理员设置的额度。 |
| 管理员 | `admin` | 无限额度，可访问用户管理、设置、账号池和运维页面。 |

## 关键目录

| 路径 | 用途 |
| --- | --- |
| `main.py` | Uvicorn/FastAPI 启动入口。 |
| `api/` | HTTP 路由层，包括系统管理、图片任务、OpenAI 兼容接口。 |
| `services/` | 业务服务层，包括配置、用户、账号、图片任务、存储后端。 |
| `web/` | Next.js 前端源码。 |
| `web_dist/` | 前端构建后的静态产物，由 FastAPI 托管。 |
| `data/` | 运行时数据目录，部署时必须持久化和备份。 |
| `docs/` | 项目文档和发布说明。 |
| `test/` | Python 接口和服务测试。 |
| `scripts/` | 辅助脚本，例如存储迁移和移动端 UI 审计。 |

| 用户管理 | `/users` | 管理员。 |
| 设置 | `/settings` | 管理员。 |
| 账号池 | `/accounts` | 管理员。 |

| 日志 | `/logs` | 管理员。 |
| 注册任务 | `/register` | 管理员。 |
